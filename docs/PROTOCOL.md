# 协议文档

## 一、泉益通 KT-10R（GT-12 / W818 平台）

- 串口：**9600 8N1**，超时 5s
- 设备：写频线为 USB 转串口（CH340 等），电台开机后响应

### 握手

```
主机 → 50 6A 4F 4A 48 23 44     ("PjOJH#D" 7字节魔数)
电台 → 06                        (ACK)
主机 → 02
电台 → 50 33 31 31 ?? ?? ?? FF   ("P311" 身份帧, 8字节)
主机 → 06
电台 → 06                        (完成)
```

### 数据帧（37 字节）

```
57  addr_H  addr_L  20  [32 字节数据]  [Σ 校验和]
```

校验和 = 32 字节数据累加和 mod 256。

### 命令

| 命令 | 含义 |
|---|---|
| `52 1B 40 20` | 读参数块（0x1B40） |
| `52 [addr_H] [addr_L] 20` | 读 32 字节 |
| `57 [addr_H] [addr_L] 20 [32B] [Σ]` | 写 32 字节 |
| `45` | 结束传输 |

### EEPROM

- 大小 0x6400 = 25,600 字节
- 块地址 0x0000-0x1F40、0x2000-0x6400（0x1F40-0x2000 为保留区）
- 每块 32 字节 = 一个频道

### 频道结构（32 字节）

| 偏移 | 字段 |
|---|---|
| 0-3 | RX 频率 BCD（8 位十进制，单位 10Hz） |
| 4-7 | TX 频率 BCD |
| 8-9 | RX QT/DQT |
| 10-11 | TX QT/DQT |
| 12 | 未知 |
| 13 | 标志（bit6-7 两位参数） |
| 14 | 标志（bit3 窄带 / bit7 禁止接收 / bit4,bit6 开关） |
| 15 | 未知 |

**频率**：`435.12500 MHz` → `43 51 25 00`

**CTCSS**：2 字节 BCD，0.1Hz 单位。`97.4Hz` → `74 09`（低字节=973%100，高字节=973/100）

**DCS**：2 字节 BCD 八进制码 + 标志。`D023N` → `23 80`；`D431I` → `31 C4`（0x80=DCS 标志，0x40=反相）

**OFF**：`FF FF`

## 二、泉盛 UV-K5 / K6

- 串口：**38400 8N1**
- 协议参考 [silenty4ng/k5web](https://github.com/silenty4ng/k5web)

### 包格式

```
AB CD  [len_lo] [len_hi]  [ XOR( data + CRC16-XMODEM(data) ) ]  DC BA
```

- `len`：data 长度（小端）
- CRC16-XMODEM：多项式 0x1021，初值 0
- XOR 密钥（16 字节循环）：
  `16 6C 14 E6 2E 91 0D 40 21 35 D5 40 13 03 E9 80`
- 整包长度 = len + 8

### 命令

| ID | 方向 | 说明 |
|---|---|---|
| 0x0514 | 主机→电台 | 初始化（`14 05 04 00 FF FF FF FF`），回复 0x0515 含版本 |
| 0x051B | 主机→电台 | 读 EEPROM：`1B 05 08 00 addr_lo addr_hi size 00 FF FF FF FF` |
| 0x051C | 电台→主机 | 读回复：`1C 05 .. .. offset size pad data[128]` |
| 0x051D | 主机→电台 | 写 EEPROM：`1D 05 [size+8] 00 addr_lo addr_hi size 01 FF FF FF FF data` |
| 0x051E | 电台→主机 | 写确认 |
| 0x05DD | 主机→电台 | 重启 |

单次读写 ≤ 0x80 字节。标准 UV-K5 EEPROM 为 0x2000（8KB）。

### 频道结构（32 字节 × 200，基址 0x0000）

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0x00 | u32 | RX 频率（单位 10Hz） |
| 0x04 | u32 | TX 频率 |
| 0x08 | u16 | RX DCS（八进制 BCD，0=无） |
| 0x0A | u16 | RX CTCSS（0.1Hz，0=无） |
| 0x0C | u16 | TX DCS |
| 0x0E | u16 | TX CTCSS |
| 0x10 | u16 | 步进索引 |
| 0x12 | u8 | 调制（0=FM 1=AM 2=USB 3=LSB） |
| 0x13 | u8 | 带宽（0=宽 1=窄） |
| 0x14 | u8 | 功率 |
| 0x15 | u8 | 扰频 |
| 0x16 | 10B | 信道名（ASCII） |

**频率**：`435.12500 MHz` → `43512500` → LE `B4 F2 97 02`

**CTCSS**：`88.5Hz` → u16 `885`

**DCS**：`D023` → u16 `0x0023`
